# PrestaFlow

Sistema de gestión de solicitudes de préstamos construido con .NET 10, React y Azure.
Arquitectura en capas (Clean Architecture), CI/CD con Azure Pipelines, Service Bus, Functions, Key Vault y Entra ID.

> 🚧 **En desarrollo.** Mirá el [roadmap](ROADMAP.md) para ver el estado actual.

## Decisiones técnicas

Las decisiones de arquitectura están documentadas como ADR en [`docs/adr/`](docs/adr/README.md): contexto, alternativas descartadas y consecuencias de cada una.
